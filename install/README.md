# Install

Claude Code: the plugin lives at the repo root, not here. See `.claude-plugin/`, `commands/`, `hooks/`, and the Install section of the top-level `README.md`.

Everything else, per tool:

- `cursor/` copy `sttp.mdc` to `.cursor/rules/`.
- `codex/` append `AGENTS.md` to your `AGENTS.md`.
- `copilot/` copy `copilot-instructions.md` to `.github/`.
- `raw/` paste `sttp.md` into the system prompt directly.
